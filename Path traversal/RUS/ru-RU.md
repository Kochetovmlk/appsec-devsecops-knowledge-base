# Path traversal (Обход пути)

Что такое обход пути?

Обход путей также известен как обход каталогов. Эти уязвимости позволяют злоумышленнику читать произвольные файлы на сервере, на котором запущено приложение. К таким файлам могут относиться:

Код и данные приложения.
Учетные данные для доступа к внутренним системам.
Конфиденциальные файлы операционной системы.
В некоторых случаях злоумышленник может записывать данные в произвольные файлы на сервере, что позволит ему изменять данные или поведение приложения и в конечном итоге получить полный контроль над сервером.

Чтение произвольных файлов с помощью обхода пути.
Представьте себе приложение для онлайн-покупок, которое отображает изображения товаров, выставленных на продажу. Изображение может загружаться с помощью следующего HTML-кода:

<img src="/loadImage?filename=218.png">
URL loadImage-адрес принимает filenameпараметр и возвращает содержимое указанного файла. Файлы изображений хранятся на диске в указанном месте /var/www/images/. Для возврата изображения приложение добавляет запрошенное имя файла к этому базовому каталогу и использует API файловой системы для чтения содержимого файла. Другими словами, приложение читает из следующего пути к файлу:

/var/www/images/218.png
Данное приложение не предусматривает защиты от атак с обходом пути. В результате злоумышленник может запросить следующий URL-адрес для получения /etc/passwdфайла из файловой системы сервера:

https://insecure-website.com/loadImage?filename=../../../etc/passwd
В результате приложение будет считывать данные из следующего файла:

/var/www/images/../../../etc/passwd
Последовательность ../действительна в пределах пути к файлу и означает переход на один уровень выше в структуре каталогов. Три последовательные ../последовательности ведут вверх от /var/www/images/корневого каталога файловой системы, поэтому фактически считывается следующий файл:

/etc/passwd
В операционных системах на базе Unix это стандартный файл, содержащий сведения о пользователях, зарегистрированных на сервере, но злоумышленник может получить доступ к другим произвольным файлам, используя тот же метод.

В Windows и , ../и ..\являются допустимыми последовательностями обхода каталогов. Ниже приведён пример аналогичной атаки на сервер под управлением Windows:

https://insecure-website.com/loadImage?filename=..\..\..\windows\win.ini

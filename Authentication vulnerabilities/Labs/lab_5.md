# Лабораторная работа: Перечисление имен пользователей с помощью блокировки учетной записи.

В этой лабораторной работе используется уязвимость, связанная с перечислением имен пользователей. Она использует блокировку учетных записей, но содержит логическую ошибку. Для решения задачи необходимо перечислить допустимое имя пользователя, подобрать пароль этого пользователя методом перебора, а затем получить доступ к странице его учетной записи.
